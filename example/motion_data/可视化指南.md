# Motion Data 可视化指南

## 方法 1：使用 vis_q_mj.py（推荐，基于 MuJoCo）

这是最简单直接的方法，使用 MuJoCo 可视化工具。

### 安装依赖

确保已安装 MuJoCo 和 mujoco_py（项目应该已经包含这些依赖）

### 使用方法

```bash
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_pose.pkl
```

### 键盘控制

在可视化窗口中可以使用以下键盘快捷键：

- **空格键 (Space)**：暂停/继续播放
- **R**：重置到开始
- **Q 或 Esc**：退出程序
- **L**：加快播放速度（×1.5）
- **K**：减慢播放速度（÷1.5）
- **J**：切换倒放模式
- **→ (右箭头)**：向前跳一帧
- **← (左箭头)**：向后跳一帧
- **Q**：修改左脚接触状态（如果 motion data 包含 contact_mask）
- **E**：修改右脚接触状态（如果 motion data 包含 contact_mask）

### 示例命令

查看不同的动作：

```bash
# 查看马步姿势
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_pose.pkl

# 查看李小龙姿势
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Bruce_Lee_pose.pkl

# 查看查尔斯顿舞蹈
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Charleston_dance.pkl

# 查看侧踢
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Side_kick.pkl

# 查看回旋踢
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Roundhouse_kick.pkl

# 查看勾拳
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Hooks_punch.pkl

# 查看马步出拳
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_punch.pkl
```

### 高级选项

```bash
# 设置播放速度（默认 1.0）
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_pose.pkl speed=2.0

# 可视化扭矩（如果 motion data 包含 tau）
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_pose.pkl vis_tau=True

# 可视化接触状态
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_pose.pkl vis_contact=True
```

## 方法 2：使用 vis_rr.py（基于 Rerun，更交互式）

这是一个更现代的可视化工具，提供更丰富的交互功能。

### 安装依赖

```bash
pip install rerun-sdk==0.22.0 trimesh
```

### 使用方法

```bash
python robot_motion_process/vis_rr.py --filepath=example/motion_data/Horse-stance_pose.pkl
```

### 特点

- 更现代的界面
- 支持 3D 交互查看
- 可以同时查看多个视角
- 支持时间轴控制

## 常见问题

### 1. 找不到 motion_file

确保路径正确，可以使用相对路径或绝对路径：

```bash
# 相对路径（从项目根目录）
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_pose.pkl

# 绝对路径
python robot_motion_process/vis_q_mj.py +motion_file=D:/__Files/lessons/_normal/ComputerGraphic/Project/PBHC/example/motion_data/Horse-stance_pose.pkl
```

### 2. 窗口无法显示

- 确保有图形界面（不是纯命令行环境）
- 检查 MuJoCo 是否正确安装
- 尝试使用 `vis_rr.py`（基于 Rerun，可能更兼容）

### 3. 动作播放太快/太慢

使用 `L` 和 `K` 键调整速度，或者使用 `speed` 参数：

```bash
python robot_motion_process/vis_q_mj.py +motion_file=example/motion_data/Horse-stance_pose.pkl speed=0.5
```

## 推荐工作流程

1. **训练前**：使用 `vis_q_mj.py` 查看参考动作，了解期望的行为
2. **训练中**：使用 `traj_vis.ipynb` 对比训练轨迹与参考动作
3. **训练后**：使用 `vis_q_mj.py` 查看模型生成的动作
